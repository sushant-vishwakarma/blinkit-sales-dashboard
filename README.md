# 📊 Blinkit Sales Dashboard

## 📌 Project Overview

This project analyzes Blinkit's sales performance using Power BI. The dashboard provides insights into sales trends, outlet performance, customer ratings, and product categories to support data-driven business decisions.

---

## 🎯 Objective

To analyze Blinkit's sales data and identify key business insights using interactive visualizations.

---

## 🛠 Tools Used

- Power BI
- Microsoft Excel
- DAX
- Data Cleaning
- Data Visualization

---

## 📂 Dataset

The dataset contains information about:

- Product Categories
- Sales
- Outlet Type
- Outlet Size
- Outlet Location
- Customer Ratings
- Item Fat Content

---

## 📈 Dashboard Features

- Total Sales
- Average Sales
- Average Customer Rating
- Outlet-wise Performance
- Product Category Analysis
- Fat Content Analysis
- Interactive Filters

---

## 💡 Key Insights

- Tier 3 outlets generated the highest sales.
- Supermarket Type 1 performed the best.
- Regular fat products contributed more sales than low-fat products.
- Fruits and snack foods were among the top-selling categories.
